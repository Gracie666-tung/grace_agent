方法論與已知限制
  • 主資料源為 Yahoo Finance 非官方 v8/finance/chart 端點，非官方 API 有中斷或改版風險； 失敗時自動改用 FRED（美國聖路易聯準銀行）公開 CSV 備援，兩者同時可用時會做交叉驗證。
  • Stooq 曾評估作為第二資料源，但其下載端點已改為需要瀏覽器互動的 JS 驗證頁，不繞過反爬機制，故未採用。
  • FRED 的銅、鋁數列（IMF 商品價格）只有月頻，不是每日更新；這兩項在本 dashboard 只顯示月/年變動率， 不套用日頻的波動度／z-score／日變動率公式。FRED 的原油、天然氣數列為日頻，但通常落後約 5 個營業日（一週）。
  • 晶片（DRAM/NAND）與塑化（PE/PP）等原物料無可靠免費公開數列來源，故未納入本工具。
  • 各品項為原幣別報價（多為美元，00715L 為新台幣），未做匯率轉換；FRED 的銅/鋁單位是 USD/公噸， 與 Yahoo 期貨的 USD/lb 尺度不同，跨來源切換時價格數字會跳動屬正常現象，不是錯誤。
  • 週/月/年變動率、波動度、z-score 皆以交易日數估算（5/21/252/30/250 個交易日），非日曆天數。
  • 某品項若當日所有資料源都失敗，會沿用既有歷史資料繼續分析並標示「今日未更新」，不會用空白覆蓋掉好資料。
  • 成本預測（naive／移動平均／線性趨勢外推）為統計 baseline，非價格預測保證，不構成採購或投資建議； 月頻品項不提供這項預測（交易日單位換算到月頻資料上沒有意義）。
